# セキュリティプロジェクトルール

このディレクトリには、バックエンドAPI開発におけるセキュリティ要件を定義したルールファイルが含まれています。

## ルールファイル構成

各セキュリティ領域は以下のファイルに分割されています：

- **@core-security.mdc** - 基本セキュリティ原則・OWASP準拠方針
- **@authentication.mdc** - 認証・認可・クッキーセキュリティ制御
- **@data-protection.mdc** - データ保護・SQLインジェクション・入出力制御
- **@infrastructure.mdc** - インフラ・ネットワーク・HTTPセキュリティ
- **@monitoring.mdc** - 監視・ログ・テスト・運用保守
